# 📒 ContactBook

> A sleek, official-looking Contact Book web app built with pure HTML, CSS & JavaScript.
> Designed with glassmorphism UI, animated background, and a smart dial pad.

---

## 🌐 Live Demo

👉 **[Open ContactBook App](https://github.com/divyalatha974-sudo/Contact_book)


### 👥 Contacts Tab
| Feature | Description |
|---|---|
| ➕ Add Contact | Save name, phone number and email |
| ✏️ Edit Contact | Update any contact's details anytime |
| 🗑️ Delete Contact | Remove with a confirmation popup |
| 🔍 Live Search | Search by name, phone or email instantly |
| 📊 Result Counter | Shows how many contacts match your search |

### 📞 Dial Pad Tab
| Feature | Description |
|---|---|
| ☎️ Single Dial Pad | One shared dial pad for all contacts |
| 🔍 Smart Suggestions | Matching contacts appear as you type digits |
| 👆 Tap to Load | Tap a suggested contact to load their number |
| ⌫ Cursor Support | Real cursor — tap anywhere to edit mid-number |
| 📱 One-tap Call | Tap 📞 to dial directly on mobile |

### 💎 Design
- Glassmorphism frosted-glass card centered on page
- Animated glowing background blobs
- Premium Inter + JetBrains Mono fonts
- Smooth hover animations on all cards and buttons
- Fully responsive on mobile and desktop

## 🧠 How Smart Dial Pad Works

```
Step 1 → Open Dial Pad tab
Step 2 → Type any digits on the keypad
Step 3 → App searches contacts in real time
Step 4 → Matching contacts appear below the screen
Step 5 → Tap a contact card to load their number
Step 6 → Press 📞 to call on your mobile device
```

## 🎨 Design Highlights

- **Glassmorphism** — frosted glass card with `backdrop-filter: blur`
- **Animated blobs** — soft glowing background that moves
- **Color system** — green `#4fffb0` + purple `#7b6fff` accent palette
- **Micro-interactions** — hover lifts, active press scale, fade-in animations
- **Centered layout** — app sits perfectly in the middle of any screen
